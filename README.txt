موقع إقرأ - متجر ومكتبة كتب (واجهة أمامية فقط)

التشغيل: افتح index.html في المتصفح مباشرة، أو من Visual Studio Code استخدم إضافة Live Server.
يحتاج اتصالاً بالإنترنت لتحميل خطوط Google Fonts (Cairo وIBM Plex Sans Arabic).

الملفات:
- index.html     الصفحة الرئيسية
- style.css      التنسيق والألوان (المتغيرات في أعلى الملف)
- data.js        الكتب والتصنيفات والكوبونات (عدّل الأسعار والبيانات من هنا)
- core.js        دوال مساعدة وتوليد الأغلفة
- shop.js        المتجر والسلة والطلب وتفاصيل الكتاب وحركة أغلفة الواجهة (renderHero: مصفوفة ids فيها الكتب السبعة)
- shelf.js       قسم كتبي (حالة القراءة والتقدم والهدف السنوي)
- reader.js      قارئ تقليب الصفحات
- pages.js       من نحن والأسئلة الشائعة والتواصل وطلباتي
- main.js        نقطة البدء
- covers/        أغلفة الكتب (تُربط بالكتاب عبر الحقل img في data.js)
- logo-mark.svg  علامة الشعار
- brand.html     دليل الهوية

كوبونات الخصم: IQRA10 وREAD25 (تُعدَّل في data.js).
ملاحظة: الأسعار والتقييمات والمبيعات أرقام تجريبية، والطلب تجريبي ولا يتم أي دفع.
